# VOLTIX24

واجهة متجر رقمية تجريبية متجاوبة مع الهاتف.

## الملفات
- `index.html` — بنية الصفحة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — تفاعل المنتجات والمحفظة التجريبية.

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة مباشرة إلى جذر المستودع نفسه.
2. افتح **Settings → Pages**.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. انتظر اكتمال النشر ثم افتح رابط Pages وحدّث الصفحة.

## تنبيه مهم
هذه واجهة تجريبية فقط. الطلبات والإيداعات تُحفظ في `localStorage` على الجهاز والمتصفح الحالي فقط. لا يوجد تسجيل دخول حقيقي، ولا قاعدة بيانات، ولا دفع أو شحن فعلي. لا تجمع أموالاً من العملاء قبل بناء backend آمن وربط مزود دفع وشحن موثوقين. لا تضع مفاتيح API السرية في ملفات الواجهة العامة.
